# IntellHire 💼

IntellHire is a simple job portal system where users can search jobs, apply after login, and track their application status. Recruiters can create accounts, set up companies, and post job listings.

---

## 🚀 Project Overview

IntellHire is a role-based job portal with three main parts:

1. **Public Users (Visitors)**
2. **Job Seekers (Registered Users)**
3. **Recruiters**

---

## 👤 1. Public Users
- Can browse available jobs
- Can view job details
- Must login/register to apply for jobs

---

## 🧑‍💻 2. Job Seeker (User Dashboard)
After login, users can:
- View personal dashboard
- Apply for jobs (CV upload required)
- Track application status (Pending / Accepted / Rejected)
- Manage profile

---

## 🏢 3. Recruiter Dashboard
Recruiters can:
- Register and login
- Create company profile
- Post new jobs
- View applicants for each job
- Manage job postings

---

## 🧩 System Features
- Authentication System (Login / Register)
- Role-based access (User / Recruiter)
- Job listing & search
- CV submission system
- Application status tracking
- Recruiter job management

---

## 🛠️ Technologies Used
- ASP.NET Core MVC
- Entity Framework Core (Code First)
- SQL Server
- C#
- Bootstrap
